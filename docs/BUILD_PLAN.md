# Full-system construction plan

Date: 2026-10-09. **Not** a chain of disposable prototypes. Each phase builds a complete integration slice of the intended architecture. Never call an unfinished slice production-ready.

## Phase I, integrated operational foundation (started)

Implement a single local engine with durable SQLite event history, typed provenance, stateful observer, memory and attributed relationships, competing persistent intentions, bounded affective regulation, state-update law, optional and noncanonical counterfactual Oracle, policy arbitration, outcome/consolidation, deterministic audit trace, reset/restart, CLI, and tests. Make the system runnable with synthetic fixtures and no external AI API. Prioritize functional correctness over poetic output. The command line is a chassis, not a fake LLM. Acceptance: deterministic replay, no speculative fact admission, forbidden actions excluded, causal ablation effects, persistent intentions and relationships, restart safety, transactional failure behavior.

## Phase II, organism-scale dynamics

Introduce learnable coupling and endogenous recurrent signals behind feature gates without bypassing the audited baseline. Competitive stable/plastic attractors, homeostatic metaplasticity, delayed eligibility traces, long-horizon tension decay, spontaneous but bounded cognition, consolidation across simulated sleep, contradictory self-belief resolution. Test lesion/graft, state restoration versus justified learning, and out-of-distribution generalization. Always preserve the baseline.

## Phase III, episodic / relational / social integration

Adapters for canonical Pretorius archive with hash-pinned imports, authored provenance, source mismatch quarantine, graph and sparse/semantic vector candidates, bidirectional self-model, social observer network, controlled symbolic cue learning and phase-aware episode boundaries. No model-generated memory promotion. Test synonym/paraphrase counterexamples and other-agent archive injection.

## Phase IV, embodied and external world

Controlled observation and authorized action adapters, commitments spanning sessions, independent environment with optional observer-conditioned world-resolution experiment and a disabled-by-default hard separation between simulator dynamics and agent autobiographical truth. Evidence that it functions in a fictional world does not imply simulator access in the physical world.

## Phase V, renderer and model transfer

Open-weight local renderer adapters, prompt-only and retrieval-only matched controls, optional activation steering explored separately, policy/action-render separation, cross-model behavioral continuity, long-lived unattended runtime with backup/restore and owner control. Equal task access, inference budget and content budgets.

## Phase VI, independent evaluation and proposed promotion

Predeclared blinded challenges across models and seeds; human-adjudicated datasets; matched ablations, gate on recall precision and recall, not abstention alone; distribution-shift and counterfactual tests; rollback and reproducibility. Only independently supported modules are eligible for optional transfer to The-Doctor-Lives, subject to its architecture and evidence contracts.

## Non-negotiable release requirements

No invented benchmarks, no rhetoric about emergent consciousness, no automatic production merge, no provenance violation, no state snapshots that cannot be replayed, and no transition where verbal style improvement substitutes for policy-level causality.
