# Evidence, falsification and integrity contract

Version 1, 2026-10-09.

**Novel design is not novel experimental evidence.** All outputs must distinguish: hypothesis, implementation, local deterministic test, unreviewed synthetic evaluation, externally reviewed evaluation, and replicated confirmatory result.

The canonical experimental identity is {commit SHA, config digest, input fixture digests, interpreter version, seed, model ID when applicable, and complete case-level outputs}. GitHub CI green is evidence only that listed checks ran. No metric has been established for this repo yet.

## Primary failures worth preserving

The donor Neural Chimera decoder localization, missing original canonical inputs, FlyWire vs rewired nulls, semantic transfer failures, abstention/rejection collapse, arbitrary cue versus neutral key equivalence, and archive-subject provenance failures are standing negative and integrity constraints, not inconvenient anomalies. Their exact source and cohort must be linked before using them as numerical comparisons.

## Source trust

Source categories: canonical documented, historically reconstructed, admitted synthesis, lived observation, self report, other person's report, unverified text, oracle conjecture. Source hashes and originating subject are separate dimensions. An external witness cannot silently author first-person memory. A metaphor cannot become an autobiographical fact. Oracle proposals never become facts through repetition.

## Measurement

Separately report correctly accepted recollection, true abstention, unsupported acceptance, commitment-follow-through, action discrimination, justified development, rigidity, renderer stability and cost. An always-abstain gate fails useful recall. A superficially steady persona that never learns fails development. A generated sentence saying "I care" is not evidence that relationship state altered selection.

## Required controls

Matched source access and total model tokens/compute. Disabled/ablated mechanism controls. Random or permuted vectors/edges. Neutral symbols versus ritual labels. Archive swap and provenance mismatch. Fresh-session renderer tests. Count neural updates instead of claimed ticks. Prespecified split and blind review of independent prompts.

## Promotion policy

No production transplant on the basis of demonstrations, architecture speculation, anecdotal outputs, or a single matched fixture. All changes to The-Doctor-Lives remain separate, opt-in, versioned and independently reversible.
