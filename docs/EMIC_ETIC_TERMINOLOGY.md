# Emic and etic terminology contract

Date: 2026-10-09. Applies to Noetic code, research papers and Pretorius fiction.

**Emic** means the story-world or practitioner label. **Etic** means the measurable
computational mechanism. These are not synonyms with demonstrated equivalence.

| Story vocabulary | Method / implementation name | Strict claim boundary |
| --- | --- | --- |
| Witness | Typed observation and subject-linked provenance | Not a special conscious observer or quantum measurement |
| Catacombs | Provenance-indexed episodic evidence retrieval | Lexical overlap cannot verify a memory |
| Egregore / Mirror Chamber | Attributed and explicitly reviewed social-belief model | Cannot inspect another person's mind |
| Sigil / Intention Furnace | Persistent goal state and bounded action-pressure | Symbol name has no special intrinsic causal power |
| Invocation | Context-triggered policy modulation | Not actual possession or external entity |
| Oracle | Seeded counterfactual proposal process | Never canonical facts or predictions |
| Circle / Banishing | Action authorization and state isolation | Not supernatural warding |
| Alchemical Chamber | Outcome-gated consolidation and template adaptation | Not transmutation or human psychological fidelity |
| True name | Transition-law signature or state fingerprint | Not a metaphysical identity key |
| Morphogenetic field | Coupled controller and slow regulation | Not a physical developmental field |
| Observer interface | Separately parameterized fictional world process | Not evidence of real-world simulator access |

Method sections should use only the right-hand operational nouns. Emic labels are
permitted in introductory motivation, narrative fiction, filenames, and readers'
guides if explicitly identified as analogies. Contrast Gothic sigils with
arbitrary neutral keys at equal content budget. Negative cue equivalence is
preserved as a standing constraint.

Refer to `docs/ARCHITECTURE_V2.md` for the actual update equations and evidence
contract. Avoid treating metaphorical names as measured mechanisms.
